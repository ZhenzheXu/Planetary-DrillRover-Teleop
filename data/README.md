# Experimental Data

This folder contains the experimental data and processed results used for the OS-Rover field demonstrations.

## Folder structure

- `raw_logs/` contains the original CSV telemetry logs recorded during the field tests.
- `processed_plots/` contains output plots generated from the recorded log data.
- `paper_figures/` contains the final processed figures used in the paper.

## Field-test scenarios

The released data correspond to three field-test scenarios:

1. Flat-sand mobility and collection test
2. Slope-sand traversal test
3. Pit-escape recovery test

The logs include telemetry information such as wheel commands, control source, drill command, collection-disc command, collection-module arm state, and actuator feedback. The processed plots summarize the task-level activity of the mobility system, drill module, arm mechanism, and collection mechanism during the experiments.
